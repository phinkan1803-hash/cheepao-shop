# ชี้เป้า | เว็บไซต์ร้านค้าออนไลน์ต้นแบบ (ภาพสินค้าแฟชั่น)

## วิธีเผยแพร่ผ่าน GitHub Pages
1. แตก ZIP และเปิดโฟลเดอร์นี้
2. อัปโหลด **เนื้อหาทั้งหมด** (index.html, app.js, style.css, README.md และ assets/) ไปยัง root ของ repository บน GitHub
3. Settings > Pages > Source: Deploy from a branch > Branch: main > Folder: /(root) > Save
4. รอ GitHub Actions แสดงสถานะสำเร็จ แล้วเปิดลิงก์ GitHub Pages

### อัปเดตทับเว็บไซต์เดิม
เปิด repository เดิม กด Add file > Upload files แล้วลากไฟล์ทั้งหมดจากโฟลเดอร์นี้ (รวม assets/) ขึ้นไป จากนั้นกด Commit changes หาก GitHub ถามเรื่องชื่อไฟล์ซ้ำให้ยืนยันการอัปเดต หากวิธีอัปโหลดผ่านเว็บไม่รองรับการเขียนทับ ให้ใช้ GitHub Desktop หรือแก้ไฟล์ผ่านหน้ารหัสต้นฉบับทีละไฟล์แทน

## ฟังก์ชัน
- สินค้าแฟชั่น 12 รายการ พร้อมภาพประกอบแนวภาพถ่าย ชื่อ รายละเอียด และราคาตัวอย่าง
- ค้นหา/กรองหมวดหมู่/รายละเอียดสินค้า/ตะกร้า/สั่งซื้อสาธิต/ประวัติคำสั่งซื้อ/รีวิว/แดชบอร์ด
- ระบบแนะนำสินค้า TF-IDF + Cosine Similarity (JavaScript)
- ใช้ localStorage ในเบราว์เซอร์; ไม่มีฐานข้อมูลออนไลน์

## ข้อควรทราบ
- **ภาพสินค้าเป็นภาพสังเคราะห์แนวภาพถ่าย** สำหรับประกอบการสาธิต ไม่ใช่รูปสินค้าของร้านหรือรูปสินค้าจริงที่ตรวจสอบได้
- ชื่อสินค้า ราคา และสต็อกเป็นข้อมูลตัวอย่าง ไม่ใช่ราคาเสนอขายจริง
- ไม่มีการชำระเงินจริง ไม่มี Google OAuth จริง ไม่มีระบบล็อกอินที่ปลอดภัยสำหรับการใช้งานจริง
- ไม่ควรกรอกข้อมูลส่วนบุคคลจริงลงในต้นแบบ
- ใช้ชื่อ localStorage ใหม่ (`cheepao-fashion-v3`) เพื่อให้ข้อมูลสินค้าชุดใหม่แสดงแทนข้อมูลเก่า
- ภาพทั้งหมดถูกบรรจุไว้ใน assets/ ไม่ต้องโหลดภาพจากเว็บอื่น
